# QC Finds Extension - Terms of Service

A simple Next.js application hosting the Terms of Service for QC Finds Extension.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is configured for Vercel deployment. Simply connect your GitHub repository to Vercel and deploy.

The Terms of Service page is available at `/legal`.

## Build

To build the project for production:

```bash
npm run build
```
